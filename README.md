# Stellar Mapping Project

This project creates a 3D visualization of nearby star systems using astronomical catalog data from Gaia and Hipparcos.

## Purpose

The goal was to process real stellar coordinate and distance data, convert it into a three-dimensional spatial model, and visualize nearby star systems within a 500-light-year radius.

## Methods

- Processed stellar catalog data from Gaia and Hipparcos
- Applied coordinate transformations and scaling
- Filtered stars by distance
- Converted catalog coordinates into 3D positions
- Exported processed data into a game-engine visualization environment
